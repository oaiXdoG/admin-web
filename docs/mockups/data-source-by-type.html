与现在的区别

现在改后
来源选项固定地址 / 按区自动发现固定地址 / 按业务类型发现（再选业务类型）
能发现的服务只有游戏服（type=logic）任何有编码的业务类型
查询目标区服logic：区服；其他：节点（nodeId）
已有的「游戏服」数据源按区自动发现升级脚本自动改为「按业务类型发现 · logic」，不用重新配置
业务服要做的—login / callback 想被查询，需要加 GM 查询接口并上报 gmPort（另行开发）
