业务服需要加的配置 / 后台自动生成的部分

业务服配置（login / callback / logic 都一样，人工填写）
# 后台上报（所有业务服统一）
admin.report-url=http://111.230.143.165/api/node/report
admin.report-secret=********

# 下面这些已有，不变
app.key=...
server.zone-id=1     # 只有游戏服有，业务配置
服务类型写在各自代码里（登录服就上报 login），不用配置。
Agent 生成的 systemd 服务（自动，用户不填）
[Service]
WorkingDirectory=/usr/local/games/daoshinvgui
Environment=ADM_INSTANCE_ID=12
ExecStart=/usr/bin/java -Xms512m ... -cp lib/* com.xxx.App
Restart=always
业务服启动时读 ADM_INSTANCE_ID 作为实例 ID；读不到就随机生成（= 未托管）。
